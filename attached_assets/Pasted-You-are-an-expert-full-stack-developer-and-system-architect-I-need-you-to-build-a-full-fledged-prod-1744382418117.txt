1. A Frontend, built with any Replit-supported framework (e.g., React) that includes:
   - A user-friendly sign-up, login, and profile creation form.
   - Input fields for age, predicted grades, current achievements, and target university/course.

       - A comprehensive description.

   - **Input Agent:** Collects and validates user input.

   - **Testing Agent:** Implements both unit tests and end-to-end tests to ensure system robustness.

3. Data Flow:
   - User input is processed by the Recommendation Agent, which directs the Scraper and Query Generation Agents.
   - The Scraper Agent carries out source-specific searches, processes data via an LLM to obtain overarching extracurricular concept names, and then formats a comprehensive web query.
   - The retrieved detailed opportunities are validated and then surfaced to the user via the Notification Agent on a dynamic dashboard.

4. Additional Requirements:
   - Ensure that searches are done separately for forums, dedicated sites, and admissions essay platforms.
   - Provide detailed error handling, logging, and documentation for each micro-agent and the overall system.
